# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in the project's issues, pull requests, discussions and other spaces agrees to follow it.

In short: be respectful and constructive, assume good intent, and focus on what is best for the project and its users. Harassment and personal attacks are not tolerated.

## Reporting

Report unacceptable behavior to the maintainer, Hanzala Afzal ([@hanzala-afzal-dev](https://github.com/hanzala-afzal-dev)). Reports are handled confidentially. You can also use GitHub's "Report content" feature on any comment, issue or pull request.

## Enforcement

The maintainer enforces this code of conduct following the Contributor Covenant's enforcement guidelines: correction, warning, temporary ban and permanent ban, depending on the impact of the behavior.
